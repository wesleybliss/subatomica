## Auth base URLs (Tailscale / remote)
- Browser must not call `http://localhost:5000` when the page is opened via Tailscale — that hits the *client* machine.
- Match flowstate: leave `VITE_BETTER_AUTH_URL` empty → same-origin; Vite proxies `/auth`, `/teams`, etc. to `127.0.0.1:5000`.
- Set `BETTER_AUTH_URL` to the *public* web origin (e.g. `https://geekom-a7.ide-cherimoya.ts.net:3011`), not the API listen port.
- `advanced.trustedProxyHeaders: true` + Vite `xfwd: true` so forwarded host/proto are honored.
