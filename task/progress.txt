## Auth / Nitro (same-origin)
- Match flowstate: Vite + `nitro()` plugin; `server/` mounts Hono via server entry for API prefixes; SPA gets the rest.
- Leave `VITE_BETTER_AUTH_URL` empty → same-origin `/auth`. No Vite proxy / vercel.json SPA rewrite.
- `BETTER_AUTH_URL` = public web origin (e.g. `https://subatomica.apps.gammagamma.co` or Tailscale `:3011`).
- On Vercel: `VERCEL=1` → nitro preset `vercel`, output `.vercel/output`. Include prod domain in `BETTER_AUTH_TRUSTED_ORIGINS`.
- `@/` alias: web vs api via importer path (`aliases.ts`); server uses `@api/`.
- Standalone `pnpm dev:api` still runs Hono on :5000 for scripts/tests.
